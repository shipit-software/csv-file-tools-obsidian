# CSV File Tools for Obsidian

Open a CSV or TSV file from your vault, edit its searchable table, and choose Save changes to save that same file. Processing stays local. No account or network service is required.

Install the release assets in a disposable test vault at .obsidian/plugins/csv-file-tools/ and enable the plugin in Community plugins. Run CSV File Tools: Open CSV or TSV file, or use a file's Open in CSV File Tools context menu. Save before quitting or disabling the plugin; unsaved drafts live only in memory.

Files: UTF-8 CSV/TSV, up to 5 MiB, 50,000 cells and 200 columns. External changes block overwriting and expose recovery text. Edited saves preserve BOM and newline conventions, with quoting regenerated when necessary.

Product: https://csvfile.tools
Privacy: https://csvfile.tools/privacy

Source code is private. This repository provides the compiled release, license, and third-party notices.

Desktop only. Requires Obsidian 1.14.5 or later. Version 0.1.1.
